## Architecture

Two-script design:
- `setup.ps1` — run once per machine; writes `config.json` next to itself
- `claude-usage-popup.ps1` — reads `config.json` via `$PSScriptRoot`; everything dynamic

Config lives next to the scripts (folder-name-agnostic via `$PSScriptRoot`).

## Critical constraints

- **UTF-8 BOM required**: PowerShell 5.1 breaks silently without it. After any WSL edit, re-encode with `python3` (see `REPORT.md` → "CRITICAL: File encoding").
- **No non-ASCII chars**: PS 5.1 chokes on `·`, `—`, `─` etc. with cryptic parse errors.
- **Port assignment**: `9221 + account_index` (1-based). Account1=9222, Account2=9223, ...
- **Chrome kill logic**: matches `CommandLine like "*$Folder*"` via WMI per-PID query — not a WQL LIKE filter (that returns 0 results on this setup).
- **IPv4 only**: use `http://127.0.0.1:$port` not `localhost` — Chrome binds IPv4 only, `localhost` resolves to `::1` on this machine.
