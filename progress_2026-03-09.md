### New file: setup.ps1

One-time wizard. Flow:
1. Checks for existing `config.json`, offers to reconfigure
2. Validates Chrome path (prompts if not found at default)
3. Asks account count (1–9)
4. For each account: launches Chrome with `--user-data-dir=Account{N}` and `--remote-debugging-port=922{N+1}`, waits for login + Enter, asks display name
5. Kills launched Chrome PIDs (tracked via `Start-Process -PassThru`)
6. Writes `config.json` next to the script via `$PSScriptRoot`

Port assignment: `9221 + i` (Account1=9222, Account2=9223, ...).

### Refactored: claude-usage-popup.ps1

Key changes — all hardcoded account data removed:

| Before | After |
|--------|-------|
| `param([string]$ChromePath, [string]$ProfilesRoot, ...)` | Config loaded from `config.json` via `$PSScriptRoot` |
| `$Script:Ports = @(9222, 9223, 9224)` | `@($Accounts \| ForEach-Object { $_.port })` |
| `$AccountNames = @(...)` | Removed — use `$Accounts[$i].name` |
| `$Script:DisplayPorts = @(9223, 9224, 9222)` | Removed — display order = config order |
| `for ($i = 0; $i -lt 3; $i++)` | `for ($i = 0; $i -lt $Accounts.Count; $i++)` |
| `$PAD + 3 * $ROW_H + ...` | `$PAD + $Accounts.Count * $ROW_H + ...` |
| `Kill-ChromeForProfile -Idx $Idx` | `Kill-ChromeForProfile -Folder $Folder` |
| `Start-DebugChrome -Idx $Idx` | `Start-DebugChrome -Account $Account` |
| `Parse-AccountInfo -Num $Num` | `Parse-AccountInfo -Name $Name` |
| `if ($i -lt 2)` (separator) | `if ($i -lt $Accounts.Count - 1)` |
